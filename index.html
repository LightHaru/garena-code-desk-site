MẤY ĐIỀU CẦN BIẾT.

Quét thấy code mới có tự thêm không?

Có. Code chưa có trong dữ liệu được tự lưu vào hàng chờ ngay khi quét, không cần dán hoặc bấm thêm lần nữa. Nút Xem code mới và bộ lọc Mới từ lượt quét giúp xem riêng các mã vừa thêm. Mã trùng và lịch sử cũ được giữ nguyên.

Code lỗi có bị thử đi thử lại không?

Không. Từ bản 1.2.2, code báo lỗi được bỏ qua và lưu lịch sử, không hẹn thử lại sau 24 giờ. Khi cập nhật, các mã đang chờ thử lại, chưa mở đổi hoặc cần kiểm tra của bản cũ cũng được bỏ qua. Quét nguồn không đưa chúng trở lại hàng chờ. Khi cần đăng nhập, xác minh hoặc bị giới hạn tốc độ, lượt sẽ tạm dừng để xử lý trên Garena rồi tiếp tục các code còn lại.

Có bảo đảm mọi code đều nhận được quà?

Code tìm thấy là ứng viên. Hiệu lực, điều kiện tài khoản và quyền nhận quà do Garena quyết định. Code Desk ghi nhận phản hồi để xử lý hàng chờ.

Có chạy khi tắt Chrome hoặc máy ngủ?

Cần giữ Chrome, tab Garena mở và máy đang thức. Khi hết phiên đăng nhập, gặp xác minh hoặc kết quả chưa rõ, cần kiểm tra trực tiếp trên trang Garena.

Cập nhật tiện ích thế nào?

Dừng lượt, chờ code đang gửi có kết quả. Tải ZIP mới, thay nội dung extension vào đúng thư mục cũ, bấm Tải lại tiện ích rồi tải lại trang Garena. Xem từng bước trong hướng dẫn.

Bản thử nghiệm dùng thế nào?

Bắt đầu với vài code và xem phản hồi ngay trên trang Garena. Giao diện có dữ liệu mẫu để xem trước; hiệu lực của code và điều kiện nhận quà do Garena quyết định.

Dữ liệu nằm ở đâu?

Tên hiển thị, code và lịch sử được lưu trong hồ sơ Chrome. Tiện ích không có máy chủ nhận lịch sử hoặc công cụ phân tích hành vi. Xem quyền riêng tư và quyền truy cập.
